# Hack The Box — CTF Writeups

Welcome to my Hack The Box (HTB) writeups repository.

This repository documents my hands-on learning journey through Capture The Flag (CTF) challenges, practical security investigations, and technical problem-solving exercises.

The focus is on understanding how systems work, investigating vulnerabilities, exploring different security concepts, and documenting the techniques and methodologies used during each challenge.

## Areas of Interest

- Hardware Security
- Cybersecurity Research
- Digital Electronics and Logic Analysis
- PCB and Gerber File Analysis
- UART and Serial Communication
- Reverse Engineering
- Digital Forensics
- Vulnerability Analysis
- Technical Documentation

## Tools and Technologies

Some of the tools and technologies explored throughout these investigations include:

- Linux and command-line utilities
- Saleae Logic 2
- Hardware analysis and debugging tools
- Digital signal and protocol analyzers
- PCB inspection tools
- Python and scripting utilities
- Git and GitHub

Each challenge writeup aims to document:

- Challenge overview and objectives
- Initial investigation and reconnaissance
- Tools and techniques used
- Step-by-step analysis and methodology
- Important findings and observations
- Final solution and key takeaways
- Supporting screenshots and evidence, where appropriate

## Purpose

The purpose of this repository is to maintain a technical record of my cybersecurity learning and practical problem-solving experience.

Rather than documenting only the final answers, I aim to explain the investigation process, understand the underlying concepts, and preserve useful technical knowledge for future reference.
